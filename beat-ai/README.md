# Beat AI MVP

A mobile-first daily challenge game: five fast rounds where humans try to outsmart AI.

## Included
- 5-question daily challenge loop
- Daily deterministic challenge order
- Score + instant feedback
- Local streak and best-score persistence
- Shareable emoji result card
- Practice mode
- Mock global leaderboard
- Beat AI Pro monetization sheet ($5.99/month placeholder)
- Responsive single-file web app

## Run
Open `index.html` directly in a browser, or deploy the `beat-ai` directory as a static site.
